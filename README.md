# Circle of Allies

A 2-player asymmetric 2D game about women's safety (Phaser 3 + React + TypeScript + Vite).
Priya (Runner) has to get home through three nights. The Barrier (Player 2, or an AI in solo mode) controls the gaps in the city:
lights, gates, signs, crowds and messages. Roles swap after every level.

- Story and design: [Circle of Allies Full Game Script and Story Bible.md](Circle%20of%20Allies%20Full%20Game%20Script%20and%20Story%20Bible.md)
- Build phases, what is done and what is left: [docs/phases](docs/phases/README.md)

```bash
cd frontend
npm install
npm run dev
```

Open the URL Vite prints. Pick "1 Player" (AI Barrier) or "2 Players" (local, shared keyboard).
Controls are listed in [docs/phases/README.md](docs/phases/README.md#controls).
